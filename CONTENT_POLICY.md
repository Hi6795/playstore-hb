# Content policy

Playstore HB accepts only a real functional project in one of four classes: complete open-source game with redistributable code **and data**; freeware with documented redistribution permission; original community homebrew submitted by its developer; or a legally redistributable port. A source-port engine may be accepted without commercial data only when it states exactly: **Requires Original Game Files — Commercial data is not included — You must legally own the original game.** The store never obtains those files for the user.

Rejected content includes fictional/AI-generated listings, fake screenshots or reviews, placeholders presented as games, nonexistent releases, retail PS4 titles, paid DLC, ROMs, license/activation data, keys, leaked SDK material, commercial assets, or packages without documented rights. Hash equality is file identity, not a safety or legal finding.

No named open-source project is automatically eligible. Reviewers must verify code/data licenses, trademarks, attribution, exact package contents, redistribution evidence, authentic media, and an actual launch on each claimed PS4 environment. Compatibility claims list only exact observed model/firmware/environment combinations.

Automated validation is not legal approval. A submitter cannot approve their own work. Reviewer approval and Publisher action are separate. Revocation immediately removes a game from the next signed catalog; clients keep the last valid catalog but show repository/revocation status when online.

The checked-in production catalog contains zero games. `DEVELOPMENT TEST DATA` may appear only in tests/development paths and publication tooling refuses it in production.
